# 🚀 Muhammed Raihan O.A — Software Developer Portfolio

A modern, high-performance personal portfolio built for **Muhammed Raihan O.A**, an MCA scholar and software engineer specializing in **Python, Java, C++, SQL, Relational Schema Modeling, and End-to-End System Delivery**.

---

## 🌟 Highlights & Key Features

- **Cybernetic Obsidian & Glassmorphism Aesthetic:** Premium dark-themed visual design tailored around Raihan's personal branding, with smooth micro-interactions, responsive grid layout, and glowing neon accents.
- **Interactive Developer Shell ("Raihan CLI"):** A fully functional terminal emulator in the browser. Supports commands like `about`, `skills`, `projects`, `schema`, `education`, `contact`, `matrix` (interactive matrix rain easter egg), and `clear`.
- **Live SQL Query & Schema Simulator:** Interactive sandbox demonstrating Raihan's database expertise. Runs queries against datasets modeled on his actual projects (Cardamom Auctions, Agro Equipment, Marketplace) with simulated execution metrics.
- **Deep-Dive System Architecture Modals:** Detailed technical modals showcasing relational schemas, entity diagrams, bidding state machines, and authentic Django model architecture.
- **Theme Accent Switcher:** Real-time palette switcher (Emerald Matrix, Electric Indigo, Cyan Pulse, Cyber Amber) with local storage persistence.
- **Synthesizer Audio Effects:** Toggleable Web Audio API sound effects for clicks, hover states, and command executions.
- **Integrated Contact & Resume Hub:** Direct one-click copy buttons for phone and email, LinkedIn integration, pre-filled mail composer, and a print-ready CV viewer.

## ⚡ How to Run Locally

You can open `index.html` directly in any modern web browser:

1. Double-click `index.html` to open it in your default browser.
2. Alternatively, start a lightweight local server:
   ```bash
   # Using Python
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`.

## 🌐 Deploy to the Web for Free

### Option 1: GitHub Pages
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   ```
2. Push to your GitHub account repository named `<your-username>.github.io` or enable GitHub Pages under **Repository Settings > Pages**.

### Option 2: Vercel or Netlify
- Drag and drop the `portfolio` folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
- Your portfolio will be live in under 30 seconds with a free custom SSL domain!
